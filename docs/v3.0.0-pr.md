# PR: release: v3.0.0

## Recommended title

`release: v3.0.0`

## Supplemental PR title for the latest branch update

`feat: add semantic search mvp`

## Summary

This release finalizes the `v3.0.0` branch with Unicode query support, safer snippet path handling, regression tests, and packaging cleanup.

The branch has since been extended with a semantic retrieval MVP so natural-language queries can recall conceptually related code even when identifiers do not share the exact same wording.

## Background

The previous release branch exposed three concrete gaps:

- Unicode and Chinese queries could be dropped during query analysis.
- Snippet file paths could resolve outside the project root.
- The repository lacked automated regression coverage for the search and snippet workflow.

This PR closes those gaps and finishes the `v3.0.0` release packaging work.

## Supplemental PR summary: semantic search MVP

This follow-up branch update adds a lightweight local semantic retrieval layer on top of the existing lexical/symbol/path search stack. It avoids external model dependencies and instead uses local semantic term generation plus semantic FTS storage to improve natural-language recall.

## What changed

- Added Unicode-aware query analysis for natural-language searches.
- Added a Unicode-friendly lexical fallback search path.
- Fixed source decoding to prefer valid UTF-8 during indexing.
- Added project-root boundary checks for `get_file_snippet`.
- Normalized `project_stats` root-path lookups.
- Added automated tests and a `npm test` script.
- Bumped release-facing version markers to `3.0.0`.
- Restricted npm package contents to release artifacts.

## What changed in the semantic MVP follow-up

- Added `semantic` as a supported search mode.
- Added semantic recall inside `auto` and `hybrid` for natural-language-like queries.
- Added local semantic term generation from identifiers, paths, symbols, and content.
- Added synonym expansion for common engineering concepts such as:
  - `login/signin/auth`
  - `handler/controller/endpoint`
  - `repository/dao/store`
- Added `chunk_semantic_fts` storage for semantic retrieval.
- Added lazy semantic backfill so existing indexed projects can participate without a forced full reindex.
- Updated:
  - `search_context` tool schema
  - Web debug panel mode selector
  - README documentation
- Added regression coverage for semantic synonym matching and protected the existing normalized-root/filter behavior.
