# PR: release: v3.0.0

## Recommended title

`release: v3.0.0`

## Summary

This release finalizes the `v3.0.0` branch with Unicode query support, safer snippet path handling, regression tests, and packaging cleanup.

## Background

The previous release branch exposed three concrete gaps:

- Unicode and Chinese queries could be dropped during query analysis.
- Snippet file paths could resolve outside the project root.
- The repository lacked automated regression coverage for the search and snippet workflow.

This PR closes those gaps and finishes the `v3.0.0` release packaging work.

## What changed

- Added Unicode-aware query analysis for natural-language searches.
- Added a Unicode-friendly lexical fallback search path.
- Fixed source decoding to prefer valid UTF-8 during indexing.
- Added project-root boundary checks for `get_file_snippet`.
- Normalized `project_stats` root-path lookups.
- Added automated tests and a `npm test` script.
- Bumped release-facing version markers to `3.0.0`.
- Restricted npm package contents to release artifacts.

## Validation

The following commands were run successfully:

```bash
npm run build
npm test
npm pack
```

## Notes for reviewers

- The release branch already contains the earlier functional fixes and version bump.
