# ace-mcp v3.0.0 Release Note

`ace-mcp v3.0.0` focuses on making the local code-search workflow more usable and safer in real projects, especially when queries or source code contain Unicode content.

## Highlights

- Supports Unicode and Chinese query token analysis.
- Preserves valid UTF-8 during indexing to avoid garbled indexed content for Chinese source files.
- Blocks `get_file_snippet` from reading files outside the project root.
- Normalizes project root lookups for `project_stats`.
- Adds automated regression tests for query analysis, search filters, metadata mode, and snippet path safety.
- Narrows npm package contents to release-facing artifacts only.

## Key Changes

### Search quality

- `queryAnalyzer` now keeps Unicode tokens instead of dropping them during normalization.
- Search adds a Unicode-friendly lexical fallback path for content matching.

### Indexing reliability

- Source decoding now prefers valid UTF-8 so multilingual files are indexed correctly.

### Safety

- File snippet resolution now validates that resolved paths stay under the project root.
- Project stats lookups normalize project roots before querying persisted metadata.

### Engineering quality

- Added `npm test`.
- Added focused regression tests around indexing, search, filters, metadata responses, and snippet boundaries.
