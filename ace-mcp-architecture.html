ace-mcp Architecture

本地图代码搜索 MCP Server：CLI 启动后同时服务 MCP stdio 与可选 Web 调试面板，共享索引、搜索、问答、摘要、长任务和 SQLite/FTS/HNSW 存储能力。

Version: 4.10.1
Runtime: Node.js + TypeScript
Storage: ~/.ace-mcp/data/index.db

架构概览

ace-mcp 是一个运行在本机的代码搜索与代码问答服务。启动进程会先加载配置、初始化 SQLite 索引库、Embedding、索引协调器、搜索服务、LLM 客户端和摘要生成器，然后同时向 MCP 宿主暴露 stdio 工具，并可选启动 Web 调试面板。MCP 工具和 Web API 共用同一套核心服务，因此搜索、定义跳转、引用分析、调用链、项目画像、摘要和智能问答的行为保持一致。

核心链路

索引链路从项目扫描开始，经过 ignore/git diff 判定、语言适配器解析、代码块切分、符号与 usage 提取，最后写入 SQLite、FTS5 和向量缓存。查询链路由 SearchService 汇合路径、全文、符号、语义向量和可选 LLM rerank；Ask Codebase 在此基础上组装 RAG 上下文，通过 OpenAI 兼容 LLM 接口返回答案，并用任务中心承载索引和摘要等长任务状态。

入口层

  • • `ace-mcp` 通过 stdio 暴露 MCP 工具给宿主。
  • • `--web-port` 启动 Express Web 面板和 SSE 问答。
  • • CLI 直接支持 doctor、eval、warm、autostart。

主链路

  • • 1 号链路负责扫描、解析、分块、符号提取和索引写入。
  • • 2 号链路负责搜索、Worker 查询、数据读取和 RAG 问答。
  • • 长任务中心承载索引、摘要等异步任务状态。

数据模型

  • • Project、File、Chunk、Symbol、Usage 是检索和调用图基础。
  • • FTS5、semantic text、Vector/HNSW 支撑多路召回。
  • • settings、logs、dataHealth 暴露可诊断的运行状态。
